## Intentionally not claimed

This repository is a learning/deployment starter rather than an auditable
double-entry ledger. Amounts remain SQLite/D1 `REAL`, source rows are mutable
cache records, and the template has no statement reconciliation, pending-row
lifecycle, FX conversion, immutable observation log, or autonomous steward.
Those are capability gaps, not hidden features. Deployers needing accounting-
grade exactness should add integer minor units and a tested migration before
using totals as books of record.

The public starter also does not contain a production deployment workflow. CI
has no Cloudflare or SimpleFIN credentials and performs no deployment. This is
deliberate: public forks must not inherit access to someone else's resources.
