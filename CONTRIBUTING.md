# Contributing

Contributions are welcome.

Before opening a pull request:

1. Run `npm run check`.
3. Keep examples generic and token-free.
4. Add or update docs for new MCP tools.
5. Do not include real finance data, statements, database/vector exports, private endpoints, Cloudflare IDs, bearer tokens, or SimpleFIN Access URLs.

Good public examples use:

- `finance.example.com`
- `<MCP_BEARER_TOKEN>`
- `<ADMIN_TOKEN>`
- fake UUIDs such as `00000000-0000-0000-0000-000000000000`
