# Ledger Maintenance

Start with live status and one concrete issue. Prefer preview, hash, then apply when
available. Preserve provider and statement observations, append corrections instead
of rewriting facts, and repeat idempotent operations to verify stable results.

Treat `expired_assumed` as reversible bookkeeping, not proof of cancellation. Keep
derived enrichment, index, model, and briefing failures isolated from ledger truth.
Never alter protected evaluation evidence automatically. Report writes, skips,
remaining uncertainty, and provenance.
