# Ledgerglass Agent Plugin template

Portable workflow instructions for a self-hosted Ledgerglass server. Replace the
placeholder URL in `mcp.json` with your own authenticated MCP gateway. Do not put
authorization headers, connector credentials, account details, or deployment IDs in
the package.

The live server's `agent_guidance` response remains authoritative. These skills teach
stable evidence, statement, and maintenance habits without copying changing tool
schemas or operational facts.
